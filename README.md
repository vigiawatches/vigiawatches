# VIGIA WATCHES · Web

Web estática (solo HTML, CSS y JavaScript).

## Subir a GitHub Pages
1. Crea un repositorio nuevo en GitHub y sube **todo el contenido de esta carpeta** (que `index.html` quede en la raíz).
2. Ve a Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save.
3. En 1-2 minutos tu web estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Qué editar
- `js/products.js`: teléfono, correo, **precios**, colores, descripciones y fichas técnicas.
- `index.html`: textos, y el bloque comentado `<video>` del banner (HERO).
- `assets/img/`: fotos (si cambias una, mantén el mismo nombre o actualiza `products.js`).
- `assets/logo/`: logos de VIGIA en SVG (plata y dorado).

## Estructura
index.html · css/styles.css · js/main.js · js/products.js · assets/{img,logo,video} · favicon.svg
